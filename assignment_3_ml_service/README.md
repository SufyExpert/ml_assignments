# Assignment 1 — Supervised ML Benchmark

I used the stroke prediction dataset from the `data/` folder and built this benchmark to compare
**7 supervised learning models**: Logistic Regression, KNN, Decision Tree, Random Forest,
Gradient Boosting, XGBoost, and SVM. I kept the workflow straightforward and transparent: load the
raw data, inspect it, prepare the features, train the models, compare the results, and then explain
what the outcomes actually mean.

---

I took the dataset from `data/stroke-data.csv` and used it as the main data source for this project.

| Requirement | My dataset |

## 3. Setup Instructions

### Step 1 — Dataset location
I used the dataset at:

```
data/stroke-data.csv
```

This is the file I used for the project, and the notebook is set up to read from that path directly.

### Step 2 — Create a virtual environment
```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
```

### Step 3 — Install dependencies
```bash
pip install -r requirements.txt
```

The project requirements include the main ML libraries, and I also noted the macOS `libomp` fix for
XGBoost in the requirements file because that is the system dependency that sometimes needs to be
installed separately on Apple machines.

### Step 4 — Run the notebook
```bash
jupyter notebook Assignment1_Supervised_ML_Benchmark.ipynb
```
Then I ran all cells to generate the outputs in the `outputs/` folder.

## 5. Notes from my run

- I used `RANDOM_SEED = 42` so the results are reproducible.
- The notebook drops the `id` column because it is just a row identifier and has no real predictive value.
- I converted the `bmi` column to numeric and treated missing values as part of the preprocessing step.
- If `xgboost` is not available, the notebook skips it cleanly instead of failing the full run.
- On macOS, the common issue is the OpenMP runtime. In my setup, that was solved by installing `libomp` with Homebrew.

```bash
brew install libomp
pip uninstall xgboost -y
pip install xgboost --no-cache-dir --force-reinstall
```

If the pip install still fails, I used the conda route as a fallback:

```bash
conda install -c conda-forge xgboost
```
